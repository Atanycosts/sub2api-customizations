# 鹈鹕实测

用户侧 `/pelican` 展示用户当前可用 OpenAI 分组中已经发布的分组测试。分组权限与 API 密钥绑定列表一致；订阅、专属分组和公开分组限制都沿用现有权限。用户不能提交测试，接口不返回账号、上游地址、原始 SSE、预算或管理员信息。

页面使用网格与分页。列表只读取摘要；卡片进入视区后加载正文，静态预览禁用脚本。详情与双作品对比在独立的无同源权限 sandbox 中播放动画，并禁止外部网络访问。单题作品用于观察绘图和指令遵循，不能作为通用智能分数。

管理员在 `/admin/pelican-tests` 设置展示开关、每日预算和测试计划。当前支持 OpenAI 分组的 Chat 与 Responses，使用现有分组调度器、渠道和账号模型映射、思考强度策略、账号并发槽及协议转发。所选账号必须为可保留明确输出 token 上限的 API Key 账号；其他平台和 OAuth 不在当前支持范围。测试不经过客户余额、用量或 Memory 流程。

每次提交冻结题目原文、版本、分组、请求模型、协议、思考强度、输出上限和预留预算，执行记录另保留实际账号、上游模型和生效参数。提交 UUID 持久幂等；网络或未知执行结果不会自动重放。账号繁忙会保存不可用结果。执行串行，最长三分钟、响应上限 2 MiB，定时频率至少三十分钟；重启不补跑错过的轮次。

预算按 UTC 日计算，保守占用每次完整预留和已知估算成本中的较大值；估算按本站模型价格，不是供应商账单。未知执行继续占用预留。每日预算设为零可停止新测试，同时保持已发布结果可见；关闭全局开关会暂停新执行并隐藏用户结果。暂停计划停止未来定时运行，已开始的运行完成；手动运行不改变原定的下次运行时间。

每个计划保留最近一百次、七天内的完整结果，成功和失败均保留。过期时清理产物、原始响应和用量正文，独立的预算及幂等记录仍保留。计划删除使用软删除，用户立即不可见。

历史 `gateway_operations_experiments` 是账号直测，继续保留在网关运维观察中，不迁移或冒充为分组实测。迁移 `254_pelican_group_tests.sql` 仅增加三张独立表；回滚旧二进制前应暂停新测试。
